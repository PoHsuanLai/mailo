# mailo-editor

The composer's rich-text document, as pure edits: one column of paragraphs and atomic objects,
five operations that each return their inverse, undo, markdown shortcuts, the `/` menu, and
writers to HTML and `format=flowed`. Nothing here draws, reads a clock or touches a disk.

Part of [mailo](https://github.com/PoHsuanLai/mailo). Licensed under MIT or Apache-2.0, at your
option.
