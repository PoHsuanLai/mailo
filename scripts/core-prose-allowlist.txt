# mail-core files that still name a terminal command in a string: `mailo account add …`,
# `mailo sync`, and so on.
#
# These modules still return terminal prose. A front-end should word a result for itself, so each
# is to be converted to a typed outcome (a value the window and the command line each render in
# their own words), and its line removed from this file when it is. The list only shrinks:
# scripts/check-boundary.sh fails on a mail-core file with such a string that is not listed, and
# on a listed file that no longer has one.
#
# One repository-relative path per line.
# What is left is the Display of error types: `#[error("... mailo sync ...")]` hints that every front
# of the library shows today. Wording an error for a front-end means mapping `CoreError` in
# mail-app's cli (it is converted to a `String` with `?` in many places), which is its own lane.
